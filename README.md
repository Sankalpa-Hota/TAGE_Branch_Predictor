# TAGE Branch Predictor (SystemVerilog)

A 6-table **TAGE** conditional branch predictor in synthesizable SystemVerilog, inside a **64 Kbit** budget (uses ~53 Kbit).

- **Bimodal base** (4096 × 2b) + **6 tagged tables** with geometric history lengths 4 → 128.
- **Folded history** registers: O(1) incremental compression of the 128-bit GHR into index/tag hashes.
- **2-stage pipelined prediction**: hash + SRAM read, then tag compare + longest-match select. 1 prediction/cycle.
- **SRAM-based tables** (1R1W macro model) with a power-on init sweep.
- **Useful-bit** training, allocation on mispredict with LFSR randomization, and **graceful u-bit decay** (alternating MSB/LSB clear).
- `use_alt_on_na` counter for newly allocated entries.
- Metadata travels with each branch, so updates need no table re-read.

Full design notes: [docs/DESIGN.md](docs/DESIGN.md)

## Layout
```
rtl/      tage_pkg, sram_1r1w, folded_history, tage_bimodal, tage_table, tage_top
tb/       one self-checking testbench per module
tests/    .txt stimulus + expected values (generated by scripts/gen_tests.py)
docs/     DESIGN.md
```

## Run
```
make              # all testbenches, Verilator
make SIM=icarus   # same with Icarus Verilog
make top          # full predictor on the branch trace
make lint         # verilator -Wall on the RTL
make vectors SEED=7
```

Sample result on a 31K-branch trace:
```
TAGE    mispredicts 74.40 per 1K branches
bimodal mispredicts 239.78 per 1K branches   (3.2x worse)
learnable branches after warm-up: 97.4% correct
PASS tb_tage_top
```
